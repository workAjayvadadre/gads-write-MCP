The one that changes the picture

run_gaql_query lets Claude write its own query against Google's reporting language. That means any reporting question is answerable without anyone building a new tool — ad-level performance, device and geography splits, conversion actions, assets, change history, hourly breakdowns. You ask in English; Claude writes the query.

Blocked from it: the resources that expose people and payment plumbing rather than advertising performance — user access lists, billing setups, invoices, payment accounts.

Every one of these returns a preview and nothing else. A separate approval step applies it, and that step re-checks everything against the account as it stands at that moment. Nothing is ever removed or deleted — pausing is reversible, deletion is not, so there are no delete tools at all.

03   What still needs the UI

Two gaps are worth calling out because they affect ordinary work rather than edge cases.

Pausing a keyword or an ad

You can pause a whole campaign, but not one bad keyword or one underperforming ad. That is a routine action, and today it means opening the UI. Probably the highest-value tool still missing.

Finishing a new campaign

create_campaign makes a paused shell with a budget and a bidding strategy. Everything that makes it a real campaign — locations, ad groups, keywords, ads — is then partly here and partly in the UI. Useful, but not yet an end-to-end launch.

The honest summary

Supermetrics is a reporting product that has added some campaign management. This is a campaign management product with reporting attached. If you want one number that combines Google, Meta and LinkedIn spend, Supermetrics wins outright and this server cannot help. If you want someone to change a budget without being able to do it wrong, Supermetrics has no answer and this does.

The difference that actually matters

Supermetrics can change a campaign. What it does not have is the thing this server was built entirely around: a change is drafted, shown to a person in plain English, approved, and recorded. Nothing here can be applied by an AI acting alone, and every attempt — successful or refused — is written down against the person who made it.

For reading data, that machinery is overhead. For spending money, it is the whole point.

Where this one is genuinely unusual

  • No stored credential. Every call uses the individual's own Google login. Remove someone in Google Ads and they lose access here immediately, with nothing to redeploy. Most connectors share one service credential, so everyone has the same power and the audit trail says "the connector did it".
  • Permissions come from Google Ads itself, per account. Someone can be an admin on one account and read-only on another, and this respects that automatically.
  • Approval is enforced by the server, not by the AI's good behaviour. A client that cannot show an approval prompt is refused rather than allowed through.
  • Nothing can be deleted. Not a policy — there is simply no tool for it.

That combination is not something the off-the-shelf options offer. It is also the reason this took real effort to build rather than being an afternoon's API wrapper.

06   What to use for what

Use this server

Daily Google Ads management — search terms, negatives, budgets, pausing, bids, keywords, ad copy. Any Google Ads question. Anything where a person should see and approve a change before it happens.

Use Supermetrics

Anything spanning more than one channel. Recurring reports and dashboards. Feeding a warehouse or a spreadsheet. Comparing Google against Meta in a single view.

Use the Google Ads UI

Building campaigns properly — targeting, assets, audiences. Anything outside Search. Pausing individual keywords or ads. Experiments.

Before any of this is real

This server has never been run against a live Google Ads account. Every test uses a stand-in. The capabilities above are what the code does; whether it does them correctly against Google's real API is genuinely unknown until someone pauses one campaign that does not matter and checks the result.

Everything else in this report assumes that goes well.

The strategic position is worth stating plainly: this is not competing with Supermetrics, and it should not try to. Adding 150 data sources would take years and produce something worse than what already exists. What it has that nothing on the market has is a safe, audited, per-person way to let a team change Google Ads by asking. Deepening that — pausing keywords and ads, finishing the campaign-creation flow — is worth far more than widening it.
